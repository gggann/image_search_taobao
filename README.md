# 타오바오 이미지 검색 도우미 (image_search_taobao)

Chrome / Edge 브라우저 확장 프로그램(Manifest V3)으로, 어떤 웹페이지의 상품 이미지에서든 **우클릭**하면 **타오바오 동일 상품 이미지 검색**을 사용할 수 있습니다. 또한 JD / 타오바오 / 티몰 상품 상세 페이지에「타오바오 동일 상품 검색」「mapi 동일 상품 검색」버튼을 주입하여 빠르게 가격을 비교하고 동일 상품을 찾을 수 있도록 도와줍니다.

## 주요 기능

- 🖱️ **우클릭 동일 상품 검색**: 어떤 `<img>` 이미지에서든 우클릭 →「用淘宝以图搜同款(타오바오 이미지로 동일 상품 검색)」선택 시, 타오바오 이미지 검색 결과 페이지로 자동 이동합니다.
- 🛒 **상품 페이지 버튼 주입**: 징둥(JD / JD.hk / 360buy), 타오바오, 티몰 상품 상세 페이지에「타오바오 동일 상품 검색」버튼을 자동으로 주입합니다.
- 🔌 **mapi 인터페이스 테스트 입구**: 타오바오 h5api(mtop) 인터페이스를 통해 `relationrecommend` 이미지 동일 상품 검색을 직접 호출하며, 결과를 새 페이지에 표시하여 디버깅 / 인터페이스 효과 비교에 사용합니다.
- 🍪 **로그인 상태 자동 재사용**: `cookies` 권한으로 타오바오 도메인 쿠키를 읽어 검색 결과의 관련성을 높입니다.

## 설치 방법(개발자 모드)

1. 이 저장소를 다운로드 / clone 합니다.
2. Chrome에서 `chrome://extensions/`로 이동합니다.
3. 우측 상단의「개발자 모드(Developer mode)」를 켭니다.
4.「압축 해제된 확장 프로그램 로드(Load unpacked)」를 클릭하고, 이 저장소의 루트 디렉터리(`manifest.json`이 있는 폴더)를 선택합니다.
5. 툴바에 확장 아이콘이 나타나면 사용할 수 있습니다.

> Edge 사용자:`edge://extensions/`로 이동하여 동일하게 개발자 모드를 켠 뒤「압축 해제된 확장 프로그램 로드」를 선택하세요.

## 사용 방법

### 방법 1: 우클릭 메뉴(모든 웹페이지)

어떤 상품 이미지에서든 **우클릭** →「**用淘宝以图搜同款**」을 선택하면, 새 탭에서 타오바오 검색 결과가 자동으로 열립니다.

### 방법 2: 상품 상세 페이지 버튼

징둥 / 타오바오 / 티몰 상품 상세 페이지를 열면「**타오바오 동일 상품 검색**」버튼(mapi 테스트 버튼 포함)이 자동으로 나타나며, 클릭하면 됩니다.

### 방법 3: 툴바 팝업

확장 아이콘 클릭 →「打开淘宝搜索页(타오바오 검색 페이지 열기)」로 직접 타오바오 검색에 진입할 수 있습니다.

## 디렉터리 구조

```
image_search_taobao/
├── manifest.json              # 확장 프로그램 매니페스트(MV3)
├── background.js              # Service Worker: 우클릭 메뉴, 이미지 업로드, mapi 호출, DNR 규칙
├── content_jd.js              # JD / 티몰 / 타오바오 상품 페이지에「동일 상품 검색」버튼 주입
├── content_taobao.js          # 타오바오 / 티몰 도메인 검색 레이어 로직 주입
├── content.css                # 주입 버튼 / 레이어 스타일
├── popup.html / .css / .js    # 툴바 팝업
├── mapi_results.html / .css / .js  # mapi 인터페이스 결과 표시 페이지
└── 淘宝mapi以图搜同款API复用文档.md  # mapi 인터페이스 재사용 설명 문서
```

## 권한 설명

| 권한 | 용도 |
| --- | --- |
| `contextMenus` | 이미지 우클릭 메뉴 등록 |
| `cookies` | 타오바오 로그인 상태를 읽어 검색 관련성 향상 |
| `declarativeNetRequest` | mapi 요청에 서명 / 요청 헤더 추가 |
| `storage` | 업로드 대기 중인 이미지 payload, mapi 결과 임시 저장 |
| `tabs` | 검색 결과 탭 열기 / 감시 |
| `<all_urls>` (host) | 모든 웹페이지의 이미지에서 우클릭 동일 상품 검색 제공 |

## 기술 스택

- Chrome Extension **Manifest V3**
- 순수 JavaScript(빌드 단계 없음, 의존성 없음)
- Chrome Extensions API:`contextMenus` / `declarativeNetRequest` / `storage` / `cookies` / `tabs`
